# Web Security

> Hands-on learning repository focused on **web application security**, vulnerability analysis, and ethical hacking techniques using industry-standard labs and tools.

---

## 📌 Overview
The main focus is on identifying, exploiting, and understanding common web application vulnerabilities through **practical labs** and **real-world scenarios**.

The labs are primarily based on:
- **PortSwigger Web Security Academy**
- **DVWA (Damn Vulnerable Web Application)**

---

## 🧪 Covered Topics

- Information Disclosure
- Authentication Vulnerabilities
- Access Control (IDOR & Privilege Escalation)
- OAuth 2.0 Security Issues
- SQL Injection (Union & Blind)
- OS Command Injection
- Cross-Site Scripting (XSS)
- Server-Side Request Forgery (SSRF)
- Race Conditions
- Path Traversal
- File Upload Vulnerabilities

---

## 🛠 Tools & Platforms

- **Burp Suite**
- **sqlmap**
- **PortSwigger Web Security Academy**
- **DVWA**
